# Chroma Chameleon

A simple-3D online hide-and-seek game built with **Godot 4.7.2**. One player is randomly
chosen as the **Hunter**; everyone else is a **Hider**. Hiders paint themselves in one of
four colors and try to blend into matching props and scenery. The Hunter uses a flashlight
and tags them before the timer runs out.

Everything works on separate screens: each player runs the game on their own desktop or in
their own Web browser tab. There is **no split screen**. The host PC is the server.

- Repository: https://github.com/peakbuild112000/Project2
- Web demo: https://peakbuild112000.github.io/Project2/

## Features

- 3 rounds of 105 seconds each, with a randomly chosen Hunter every round.
- 3 deterministic, textured maps: **Neon Alley**, **Sunset Canyon** and **Frozen Vault**.
- Camouflage system: standing still and matching nearby prop colors raises your hide value.
  A well-camouflaged hider becomes almost invisible to the Hunter until the flashlight is on
  or the Hunter gets very close.
- Hunter flashlight (`F`) and tag (`E` / right mouse button).
- Sprint with stamina, low-poly chameleon avatars, neon lighting, procedural sound effects.
- Password-protected sessions. Web clients connect over `wss://` through a tunnel.
- Offline **Practice** mode with bots uses the exact same match rules.

## Requirements

- Godot **4.7.2** (GL Compatibility renderer is used, so it runs on modest hardware).
- No external art or audio downloads are needed: all textures and sounds are generated by
  the Python scripts in `tools/` using only the standard library.

## Run from source

1. Open Godot 4.7.2.
2. Import `Project2/project.godot` (or open it from the Project Manager).
3. Press **F5** to run `scenes/Main.tscn`.

The main menu offers:

| Button | What it does |
|---|---|
| **Practice (Bots)** | Local match with 3 bots. Best way to learn the controls. |
| **Host Session** | Starts the WebSocket server on the host PC using the password and port shown in the menu. |
| **Join Session** | Connects to the URL in the "Server URL (Join)" field. |
| **How to Play** | In-game help. |

### Controls

| Key | Action |
|---|---|
| `WASD` / arrows | Move |
| `Shift` | Sprint (uses stamina) |
| `1` - `4` or mouse wheel | Paint yourself cyan / pink / gold / lime |
| `F` | Toggle flashlight (Hunter only) |
| `E` or right click | Tag a nearby hider (Hunter only) |
| `Esc` | Pause / resume / leave match |

## Multiplayer

The host PC runs the authoritative match server on TCP port **9080** (WebSocket/JSON
transport). Clients can be desktop builds or Web exports.

### 1. Host

- Enter a **session password** (6+ characters) and keep the default port `9080`.
- Click **Host Session**. The lobby shows the password and lets the host change the map.
- Give the join URL and password to your friends.

### 2. LAN clients (desktop or browser on the same network)

- Allow inbound TCP port 9080 on the host (Windows Firewall example):
  `tools/allow_firewall.bat` (run as Administrator).
- Join with `ws://<HOST_LAN_IP>:9080`, e.g. `ws://192.168.1.42:9080`.
- Find the host LAN IP with `ipconfig` on the host.

### 3. Web clients over the Internet (Cloudflare quick tunnel)

Because GitHub Pages is HTTPS, browser clients must use `wss://`. A Cloudflare quick tunnel
gives you a temporary public HTTPS address that forwards to the host's port 9080:

1. On the host, start the game and click **Host Session**.
2. Run `tools/start_tunnel.bat` (double-click). On first use it downloads `cloudflared.exe`
   into `tools/downloads/` (which is gitignored).
3. Copy the printed URL such as `https://random-name.trycloudflare.com`.
4. Open the Web demo with the tunnel as a query parameter:

   ```
   https://peakbuild112000.github.io/Project2/?server=wss://random-name.trycloudflare.com
   ```

5. Enter the same session password and click **Join Session**.

The `?server=` parameter overrides the automatic URL detection in
`Net.default_client_url()`. Without a tunnel, Web clients only work when the game is served
from the same machine/network as the host.

> The tunnel URL changes every time you restart `cloudflared`. Send the new URL to your
> friends each session.

## Build the Web export

Export templates for 4.7.2 are required. Once installed, use the included
`export_presets.cfg` profile named **Web**:

- In the editor: **Project → Export → Web → Export Project** into `docs/`.
- Or from the command line:

  ```powershell
  & "C:\path\to\Godot_v4.7.2-stable_win64_console.exe" --headless --path . --export-release Web docs/index.html
  ```

The `docs/` folder is served by GitHub Pages. Commit the generated files (`.wasm`, `.pck`,
`.js`, `.html`, `.png`, `.ico`, `.json`) together with the source so the demo is live.

## Headless checks

These commands were used to validate the game without a window:

```powershell
$tool = "$env:LOCALAPPDATA\OpenCodeTools\godot\Godot_v4.7.2-stable_win64_console.exe"

# Practice smoke test (bots, arena, HUD)
& $tool --headless --path . --quit-after 400 -- --auto-practice

# Network handshake: start the host in one terminal...
& $tool --headless --path . --quit-after 1200 -- --auto-host

# ...then a client in another terminal
& $tool --headless --path . --quit-after 700 -- --auto-join
```

Expected output includes `SMOKE: phase=playing players=4 ...`, `welcome`, `AUTHENTICATED`
and `CHAMELEON JOINED`.

## Project layout

```
Project2/
  project.godot            Godot project config (autoloads: GameState, AudioManager, Net)
  scenes/Main.tscn         Main scene
  scripts/
    Main.gd                Menus, camera, local input, network glue
    Net.gd                 WebSocket server/client, JSON messages
    MatchDirector.gd       Authoritative lobby, rounds, scoring, tag rules
    Arena.gd               Builds the textured 3D maps
    ArenaData.gd           Deterministic seed-based layouts
    Player.gd              Low-poly chameleon avatar and camouflage fade
    HUD.gd                 Overlay (role, timer, score, camo meter, roster)
    GameState.gd           Saved profile/settings
    AudioManager.gd        Procedural WAV playback
  assets/audio/            Generated WAV sound effects and music loop
  assets/textures/         Generated tileable PNG textures
  tools/                   Asset generators, firewall and tunnel helpers
  docs/                    GitHub Pages Web export (generated)
  ERROR_LOG.md             Errors encountered during development and their fixes
```

## Notes

- The editor plugin `godot_super-wakatime` is present but disabled in `project.godot` so it
  does not pop up an API-key dialog when you open the project. Re-enable it in
  **Project → Project Settings → Plugins** if you use Wakatime.
- All source and documentation are in English; generated assets are original and local.
