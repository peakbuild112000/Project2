# Chroma Chameleon

An original multiplayer hide-and-seek game built with **Godot 4.7.2**. All code,
textures and sounds are generated by the project: no assets from the Steam game
are reproduced.

- Repository: <https://github.com/peakbuild112000/Project2>
- Engine: Godot 4.7.2 stable (GL Compatibility renderer)
- Reference resolution: **1354 × 648**

## How it works

Each round, one player is the **Seeker** and the others are **Hiders**. Hiders
start with a white suit and must paint it to blend into the maps. Standing still
near a prop of a similar colour increases camouflage.

The Seeker uses a flashlight to find Hiders. **Spotting or shooting a Hider
eliminates them instantly.** There is no scoring system: the Seeker wins by
eliminating every Hider, and a Hider wins by surviving until the timer ends.
There are 3 rounds on 3 deterministic generated maps.

## Painting your character

- **Hiders are always in third person**; the **Seeker stays in first person**.
- Press **`P`** (Hiders only): the cursor is unlocked and the **PAINT** panel
  appears.
- Pick **any colour** with the HSV/RGB picker (unlimited colours), or use keys
  `1`–`5` for quick full-colour presets.
- Choose a brush size: **Small / Medium / Large**. Small is 3 px for fine
  strokes.
- **Left-drag on your avatar** to paint. The brush raycasts the exact body part
  under the cursor, and each body part has its own cell in the texture atlas:
  the stroke appears where you clicked and is synchronized over the network.
- **Right-drag** orbits the third-person camera only. The character keeps its
  own facing direction and does not turn with the brush view (Hiders in PAINT
  mode only).
- **Mouse wheel** zooms the camera in and out in PAINT mode.
- The **Pipette** samples the colour **as rendered on screen**, including
  lighting and shadows. A red prop in a dark corner gives a dark red, not a
  bright one. It works on your suit and on the scenery (with a material-colour
  fallback if screen capture is unavailable).
- Press `P` or `Escape` to exit PAINT mode.

## Controls

| Key | Action |
| --- | --- |
| `WASD` | Move (physical keys: `ZQSD` on AZERTY also works) |
| Arrow keys | Look (orbit the camera in PAINT mode) |
| `Shift` | Sprint |
| `Mouse` | Look (cursor captured outside PAINT mode) |
| `Right-drag + mouse` | Orbit the camera only, no character turn (Hider, PAINT mode only) |
| `Mouse wheel` | Zoom (Hider, PAINT mode only) |
| `P` | Enter / exit PAINT mode (Hider) |
| `1`–`5` | Quick colours (full repaint) |
| `F` | Flashlight (Seeker) |
| `Left click` / `E` | Shoot (Seeker) — instant elimination on hit |
| `Escape` | Pause / resume, or exit PAINT mode |
| `L` | Leave the match (from pause or PAINT mode) |
| `Enter` | Start the match in host mode |

## Running the project

1. Open Godot 4.7.2 and import `project.godot`.
2. Press `F5` to run `scenes/Main.tscn`.
3. Choose **HOST SESSION**, then have at least one other real player choose
   **JOIN SESSION** with your IP address.
4. The host presses `Enter` to start once everyone is connected.

The UI is drawn on a 1280 × 720 surface, then scaled and centred
automatically. It stays correct at the reference resolution and at other
window sizes.

## Multiplayer

**HOST SESSION** opens an authoritative WebSocket server on TCP port `9080`.
Clients use **JOIN SESSION** with `ws://<HOST_IP>:9080`. Both actions replace the
main menu with a dedicated **LOBBY** screen showing the connection status;
**CANCEL** returns to the menu. Web builds need a
`wss://` URL (for example through a Cloudflare tunnel) because GitHub Pages uses
HTTPS. The host presses `Enter` to start. **Only real players are allowed**:
at least 2 connected players are required, and no bots are ever spawned.

Painted colours and shots are synchronized: the server is authoritative and
clients only send their intent.

The **Godot Super-Wakatime** addon (v2.1.0) is installed in `addons/` and enabled
in `project.godot`. It ignores headless runs and CI.

## Structure

```
project.godot          configuration, Core and Net autoloads, Wakatime addon
scenes/Main.tscn       single scene
scripts/Core.gd        palette, maps, procedural textures and sounds
scripts/Net.gd         WebSocket transport (server/client)
scripts/Match.gd       authoritative round, role and elimination rules
scripts/World.gd       arenas, paintable avatar texture, camouflage
scripts/HUD.gd         interface, colour picker, brushes, pipette
scripts/Game.gd        main controller, paint, shooting, physics, camera
addons/                Godot Super-Wakatime addon
```
